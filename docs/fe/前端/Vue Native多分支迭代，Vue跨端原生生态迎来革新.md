### 3.2.2 纯标准Vue3开发体验

- **语法全覆盖**：100%兼容Vue3全部特性，包含Composition API、script setup、响应式系统、Vue Router、Pinia等官方工具链；

- **无额外学习成本**：沿用SFC单文件组件写法，通过view、text、image等标签映射原生控件，CSS直接作用于原生组件；

- **极速工程体验**：基于Rust构建工具，打包速度、热更新速度大幅优化，热更新实现秒级生效。

### 3.2.3 多端输出与兼容性
